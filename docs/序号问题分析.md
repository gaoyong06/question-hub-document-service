# docx → markdown 序号处理问题分析

## 一、现象

源文档：`/Users/gaoyong/Downloads/题库/一年级-数学/一年级上册数学期末测试卷（达标题）.docx`

转换后的 `4.md` 中，序号相关输出示例：

| 位置 | 实际输出 | 说明 |
|------|----------|------|
| 第5行 | `1.哪个是正方体？（   ）` | 题号 `1.` 后无空格 |
| 第9行 | `2.下面多得是（  ）。` | 题号 `2.` 后无空格 |
| 173-183行 | `1.×` `2.√` `3.×`... | 参考答案判断题，题号后无空格 |

## 二、根因分析

### 1. 题号规范化正则不匹配「半角点」

`document_parser.py` 中的 `_normalize_markdown_list_markers` 使用：

```python
QUESTION_NUMBER_NORMALIZE = re.compile(r"^(\d+)[．、]\s*", re.MULTILINE)
```

- 只匹配**全角点 `．`** 和**顿号 `、`**
- **不匹配半角点 `.`**

Word 中题号大多使用半角 `.`，例如：`1.哪个`、`2.下面`。因此这些行不会被规范化，输出中题号后仍无空格。

### 2.  downstream 解析依赖「数字 + 点 + 空格」

`exam_structure_utils.py` 中：

- **QUESTION_START_PATTERN**：`r"^\d+[\.．、]\s*"` —— 包含半角 `.`，可匹配 `1.` 或 `1. `
- **QUESTION_SPLIT_PATTERNS**：`r"(?:^|\n)\s*(?=\d+[\.．、]\s)"` —— 要求点后至少有一个 `\s`
- **parse_reference_answers**：`r"\d+[\.．、]\s*"` —— 点后可无或有空格，能匹配 `1.` 和 `1. `

因此：

- `1.哪个` 无法满足 `QUESTION_SPLIT_PATTERNS` 中「点后必须有空格」的约束
- 按题号拆题时，可能出现无法正确切分小题的情况

### 3. 设计预期

`UNIFIED_MARKDOWN_SOURCE_DESIGN.md` 要求：

> 将**题号/选项序号**统一为 Markdown 格式（`1. ` / `A. ` 半角点+空格），便于后续 markdown 转试卷结构时正则与层级更清晰。

即：题号应为 `数字 + 半角点 + 空格`，例如 `1. `、`2. `，而不是 `1.`、`2.`。

## 三、修复方案

在 `QUESTION_NUMBER_NORMALIZE` 中增加对**半角点 `.`** 的匹配：

```python
# 修改前
QUESTION_NUMBER_NORMALIZE = re.compile(r"^(\d+)[．、]\s*", re.MULTILINE)

# 修改后：增加半角 .，与 exam_structure_utils 的 [\.．、] 一致
QUESTION_NUMBER_NORMALIZE = re.compile(r"^(\d+)[\.．、]\s*", re.MULTILINE)
```

这样：

- `1.哪个` → `1. 哪个`
- `2.下面多得是` → `2. 下面多得是`
- `1.×` → `1. ×`（参考答案）
- 已含空格的 `1. 题目` 会匹配并保持为 `1. 题目`

修复后，题号格式统一，与 `QUESTION_SPLIT_PATTERNS` 等正则一致，可正确切分小题。
